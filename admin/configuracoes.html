Sobre os dados deste painel

Por padrão, os produtos, encomendas, clientes e demais dados ficam salvos no navegador (localStorage) — ótimo para testar e usar em um único computador. Para acessar de vários aparelhos, com fotos e login realmente seguro, o próximo passo é conectar o projeto ao Firebase (Authentication + Firestore + Storage). Quando quiser evoluir para isso, é só pedir — a estrutura de dados já foi pensada para essa migração (coleções: products, categories, orders, customers, materials, finances, settings).
